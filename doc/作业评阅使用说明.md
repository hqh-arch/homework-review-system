# 作业评阅使用说明

本版本支持在线文本作业及选中文字批注，不支持上传和批改 PDF、Word 或图片。

## 初始化

1. 备份现有数据库，在项目连接的 MySQL 数据库中执行 `doc/sql/homework.sql`。脚本只创建作业相关的新表，不会自动配置账号。
2. 若依系统中先创建教师和学生账号，并在现有 `hello_banji` 表中维护班级。通过以下查询找到实际 ID：

```sql
SELECT user_id, user_name, nick_name FROM sys_user WHERE del_flag = '0';
SELECT id, name FROM hello_banji;
```

3. 为每个账号配置班级成员关系（替换示例 ID）：

```sql
INSERT INTO hw_member (user_id, class_id, role) VALUES
  (教师账号ID, '班级ID', 'teacher'),
  (学生账号ID, '班级ID', 'student');
```

一个用户可属于多个班级；教师只能批改自己发布的作业，学生只能查看本班作业与自己的提交。现有学生信息记录没有自动绑定若依账号，必须使用上述成员表明确配置。

4. 按现有项目方式启动后端和前端，登录后访问 `/homework/index`。若侧边栏未出现入口，可直接访问该地址。

## 使用

教师选择班级发布作业。学生打开作业填写文本并提交。教师选择作业，从左侧选择已提交的学生，选择右侧文字并添加批注，填写分数和评语后保存。学生重新打开作业即可查看标注及结果。学生再次提交会清除已有批改；截止后不能再提交。

教师可在作业详情点击“删除作业”，删除后师生不再看到该作业，原数据保留在数据库中。教师可打开学生提交并点击“打回作业”，填写原因；打回会清除该份提交已有评分和批注。学生能看到原因并修改重交，打回后的重交不受原截止时间限制。

已有旧版数据库需要先执行 `doc/sql/homework_upgrade_return.sql` 一次，新安装使用更新后的 `homework.sql` 即可。
